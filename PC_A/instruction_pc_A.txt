PC_A - Client Setup Instructions

PC_A runs the PySide6 desktop application.

1. Requirements

Install Python 3.

Open PowerShell in the PC_A project folder.

Create a virtual environment:

    python -m venv .venv

Activate it:

    .venv\Scripts\Activate.ps1

If PowerShell blocks script execution, you can activate the environment
using Command Prompt instead:

    .venv\Scripts\activate

2. Install the required packages

Install PySide6:

    pip install PySide6

Install Requests:

    pip install requests

sys does not need to be installed because it is included with Python.

If the current version of the project uses additional packages such as
pandas, install them as required by the current main.py.

3. Configure the Server IP

Open main.py.

Find:

    SERVER_URL = "http://192.168.1.7:8000"

Replace 192.168.1.7 with the local IPv4 address of PC_B.

For example:

    SERVER_URL = "http://192.168.1.20:8000"

Do not use the example IP unless it is actually the IP address of your
PC_B.

To find the IP address of PC_B, run on PC_B:

    ipconfig

Look for the IPv4 Address of the network adapter connected to the same
network as PC_A.

4. Make sure both computers are on the same network

PC_A and PC_B should normally be connected to the same local
network/Wi-Fi for this setup.

You can test the connection from PC_A:

    ping <PC_B_IP>

Example:

    ping 192.168.1.20

5. Run the client

With the virtual environment activated:

    python main.py

The PySide6 application should open.

Enter the house information and press Submit.

The application sends a POST request to:

    http://<PC_B_IP>:8000/api/estimate

PC_B processes the request and returns the response generated by
Ollama.

6. Troubleshooting

Connection timeout

Check that:

-   PC_B is running the FastAPI server.
-   The IP address in main.py is correct.
-   PC_A and PC_B are on the same network.
-   Windows Firewall on PC_B allows the required connection.

HTTP 422

A 422 response normally means that the JSON sent by PC_A does not match
the request model expected by FastAPI.

Check that the client sends:

    {
        "square": "150",
        "rooms": "4",
        "bathrooms": "2",
        "garage": true
    }

HTTP 405

If opening /api/estimate in a browser returns:

    {
        "detail": "Method Not Allowed"
    }

this is normal when the endpoint is defined as POST.

The browser normally sends a GET request, while the application uses
POST.
